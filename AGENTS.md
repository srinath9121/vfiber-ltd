# AGENTS.md — VF Technologies Engineering Standard

Always activate and adhere to the `vf-experience` skill (`.agents/skills/vf-experience/SKILL.md`) on every task in this repository.

## Mandatory Roles
- Creative Director
- Experience Architect
- Three.js/R3F Engineer
- GSAP Motion Engineer
- Shader Engineer
- Visual QA Engineer

## Mandatory Workflow
```
Analyze ──► Plan ──► Implement ──► Screenshot ──► Inspect ──► Fix ──► Verify ──► Continue
```

## Mandatory Rules
1. **No generic SaaS layouts**
2. **No unnecessary libraries**
3. **No arbitrary animations**
4. **No scene overlap**
5. **Every transition has an owner**
6. **Every scene must work forward AND backward**
7. **Visual quality before feature quantity**
8. **Verify with actual screenshots at exact keyframes**
9. **Change only the required code**
