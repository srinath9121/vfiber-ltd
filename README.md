# VF Technologies

Interactive 3D Web Experience for Venkateswara Fiber Technologies.

## Features
- **3D Globe & Earth Engine**: Transatlantic optical route visualization.
- **Regional Telemetry Grid**: US network infrastructure nodes.
- **Telecom Hardware Simulation**: High-precision steel lattice tower.
- **Signal Transition & Fiber Core**: Procedural GPU GLSL shaders.

## Tech Stack
- Three.js
- GSAP
- Vite

## Quick Start
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
